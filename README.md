# I-Tech Management System

Database course project (Group 13): an electronics store management system built with Java (JavaFX + Maven) on a MySQL database.

## Structure

- `phase1/` – Project idea
- `phase 2/` – Phase 2 report
- `phase 3/` – Report and final ERD
- `phase 4/` – Phase 4 submission: SQL scripts, runnable JAR, source code, and required libraries
- `Final_Phase_1231891_1230834/` – Final submission: SQL scripts, report, and the JavaFX application source (`I-Tech_Management_System/`)

## Running

1. Create the database in MySQL using `Final_Phase_1231891_1230834/I-Tech_Management_System/I_tech.sql`.
2. Set your MySQL username/password in `DBconnection.java`.
3. From `Final_Phase_1231891_1230834/I-Tech_Management_System/I-Tech_Management_System/`, run `mvn clean javafx:run`.
